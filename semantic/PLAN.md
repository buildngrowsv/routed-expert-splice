# Semantic repair and routing decision

All four variable-name patches compile and run. One returns a requested field after randomly permuted bindings and up to three exchanges. Each template includes a public example and twelve concealed input vectors with distinct entries. Score actual outputs. Each pair uses the identical body and changes only the requested field and its expected example. Require both partners correct as a secondary measure. Inputs are newly generated. The exact example interpreter is a 100% ceiling, and a compiler alone has four legal choices.

One decision per path. Screen 128 matched pairs, then independently confirm on 192 validation pairs. Require a five-point single-item discovery advantage and a positive paired, pair-clustered 95% confirmation interval for standalone Qwen2.5-Coder-0.5B over Qwen2.5-1.5B. Fit the native host block 28 on 1,536 training problems using the previous one-epoch budget and seed 101 to measure headroom. Advance to the expense of a forced transplant only if the donor still leads that task-trained host by five points on validation. If it qualifies, use the other two paired seeds and the original six controls and track donor-dependent new solves. Otherwise bank the negative gate.

Independently, if an oracle choosing the correct standalone expert per problem could beat the better fixed model by at least five validation points, try one cheap inference router. Use the native host's top-two candidate margin. A single threshold fitted on validation sends uncertain examples to the independent complete coder. Fit for accuracy with ties favoring fewer calls. This is a sequential cascade, distinct from an internal MoE. Compare both standalone endpoints, oracle, and the proportion of examples requiring a second forward. A model is Pareto dominated if one endpoint achieves at least its accuracy with no greater estimated compute. Report the held-out panel (256 pairs) for every committed condition once. Pair bootstrap over base programs. Do not search different widths, prompts or thresholds on test.
