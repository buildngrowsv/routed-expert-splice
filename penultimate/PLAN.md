# Does the next host block learn to use a transplanted expert?

Decision recorded before scoring the new panel. Move the same frozen 13.1M-weight coder feed-forward network from host block 28 to block 27, numbering from one. Keep host attention, the residual path and vocabulary head intact. The only gradient-trained part is the complete host block 28. Fit new affine interfaces on block 27 training activations because their distribution changes with depth.

Retain six matched conditions: native host, feed-forward output set to zero, direct affine reconstruction, neuron-shuffled coding donor, same-sized general donor and intact coding donor. Use exactly the original training and validation splits, four target positions per 64-token window, source revisions, ridge rule and shuffle. Use a fresh test panel disjoint in window offsets and hashes from the three previous panels, sampled from the original held-out files. Keep routing off. Each replacement is mandatory.

For each condition compare its original frozen block 28 with the same block fully trainable. Use seeds 101, 211 and 307, paired window order, Adam at 0.00002, batches of 16, one epoch (96 updates). Minimize per-token squared error against the untouched host's final residual, normalized by teacher mean square plus 0.01. Use a shared validation criterion, mean full-vocabulary next-token negative log likelihood, to select among updates 0, 8, 32 and 96. Ties keep the earlier state. Metrics are held-out next-token loss in nats and exact top-one accuracy, separately for code and documentation.

The primary learning test is the change in the coding donor's on/off advantage after adaptation: [loss(off) − loss(on)] with trained block 28 minus the same quantity with frozen block 28. Positive means training made the expert more useful to this host under removal. Also compare gains from adapting with shuffled, direct, general and zero replacements. Cross the coder-trained and shuffle-trained host blocks with both grafts. A positive mean mismatched-minus-matched loss indicates the host specialized to the training interface. Shuffling and refitting can change output distributions, so this diagnostic alone does not establish transfer of coding knowledge.

Call the result evidence of increased donor use on code only if adaptation improves the coder condition by at least 0.02 nats and the paired 95% file/seed bootstrap interval for the primary interaction clears zero. Report the general-donor comparison separately before attributing any effect to code specialization. Report all arms and both domains regardless of outcome. This is a local repair experiment at one depth, context length and training budget. It does not identify an optimal depth or measure program correctness.
