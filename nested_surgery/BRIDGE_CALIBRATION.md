# Can paired calibration recover the coding expert’s input signal?

The archived input map reversed the final 7B coding module’s bracket signal on average when it read the 14B host. Keep both models frozen. Compare that archived map with two new affine ridge maps fitted to the same 512 groups of matched activation vectors. One uses ordinary least squares with a ridge penalty. The other gives within-group changes 16 times the weight of differences between group means by scaling deviations from each group’s mean by four. The only change within each calibration group is the opening bracket. The weighted map may recover a distinction that a fit dominated by other activation variance ignores. Neither map receives a repair label or uses any evaluation prompt. The host’s potentially recoverable signal and limitations of a linear map are both part of the question.
