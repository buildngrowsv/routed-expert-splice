# Can two independent donor operands compose into one host calculation?

A seven-coordinate map carried a single operand from the 7B coder into the 14B host. All 511 eligible addition and subtraction pairs reversed using the map. An equal-norm random change reversed zero. Reuse the exact map and frozen checkpoints on a larger task where one donor input alone cannot supply the complete answer.

Use 1,024 fresh four-version Python programs. Each contains two assignments and evaluates `left + 2 * right + constant` or `left - 2 * right + constant`. Cross the two independent operand choices to produce four distinct single-token answers. Neither operand pair contains a valid output digit. CPython verifies the unique correct assertion in every version. The 7B donor reads independent one-variable programs for each source, with distinct identifier stems. The donor programs contain neither the host operation nor the other operand. Translate each donor activation change separately and inject it only at its corresponding host assignment. Neither model is updated.

Compare six conditions. A native run must prefer all four correct answers to qualify a program. Patch only the left operand, only the right, and both in separate arms. The matched control applies both edits in orthogonal random directions with the same norm at each site. A positive control swaps both full host source states using the target version. Score each arm against its own four intended answers and require every variant to switch correctly for group success. Analyze addition and subtraction separately as well.

Require at least 100 qualifying programs, at least 60% correct for each of the two single-operand edits and the two-site positive control, and at least 60% correct for the combined donor edits. The paired lower 95% bound for the combined edit's advantage over random must exceed 20 percentage points. The result tests composition in generated, four-choice Python arithmetic. It uses known sites and paired donor inputs. Archive both donor panels, host prompts, four-choice logits, norms and source-map digest. At the observed one-operand rate, allow approximately eight minutes.
