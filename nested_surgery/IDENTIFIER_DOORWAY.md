# Can an identifier edit cross a wall through one relay token?

With two competing Python definitions, the same edit changed 498 of 512 queries that selected its class and 1 of 512 queries that selected the other class. The next test alters how that edit can move. Use a fresh panel of 256 two-definition files at indices 32000–32255, the frozen 14B host, and the same rank-25 fit from 512 single-definition calibration pairs. Only the earlier declaration receives the partner edit. Both class queries remain intact.

Begin after block 10. Run an untouched copy of the model alongside the edited copy for the next seven blocks. After each block restore every token in the edited copy to the untouched state except the source and one relay token. At the seventh block's exit restore the source too. Only the relay may carry a difference into the remaining transformer. The first relay is the assignment sign immediately after the source declaration. The other relay is the assignment sign in the other class, which can also access the source through causal attention. The controls are untouched execution and the unrestricted learned edit. This is a wall on propagation of a particular edit, implemented using activation restoration.

Require at least 100 groups where all four native answers are correct. Require the unrestricted edit to reverse at least 60% of queries to its class and at most 15% of queries to the other class. A relay supports routing through a single token if it reverses at least 35% of queries to the source class with a positive lower interval for selected-minus-other queries. Report each relay's effect on both reads, their paired difference, and the relay state displacement at release. Bootstrap by generated file. A successful route establishes sufficiency under the imposed wall. Native computation can use other routes.
