# Does the edit reach the final query token by block 17?

The unrestricted declaration edit reversed 242 of 256 reads of its class on a new panel. Restricting it to either assignment sign produced zero reversals. We will test one downstream site with two different ways of reaching it. At block 17 keep only the final query-token change. One arm lets the change propagate normally before that capture. The other allows the source and final query token to differ from native over blocks 11–17, restoring every other token after each block. At the exit both arms restore the source. The intact baseline and unrestricted edit remain the controls.

Use 256 fresh groups at indices 44500–44755 and the same frozen Qwen2.5-14B checkpoint, earlier declaration, and rank-25 calibration procedure. Both queries exist in each group. Use the same prespecified gate as the assignment relay study. Require at least 100 clean groups and a working unrestricted edit. A relay arm qualifies if it reverses at least 35% of the reads to the source class and the lower paired 95% bound for the difference from the other read is positive. Report the capture-minus-direct contrast along with both arms. Capture alone can show that the signal reached the query by block 17 through the intact computation. The restricted arm tests whether the intervening token states can be held clean without losing that effect.
