# Does an activation edit follow the definition that Python actually reads?

The previous probes supplied one identifier definition and then asked for its last letter. Here the same file defines two classes with the same attribute spelling, and the final expression chooses which class to read. This lets us use the identical hidden-state edit in two roles. If the read selects its class, the edit should change the completion. If the read selects the other class, the edit should leave the completion alone.

Freeze Qwen2.5-14B and use the previously specified 512 single-definition calibration pairs and 25 directions after block 10. At each of 256 fresh program indices, generate two versions of a valid Python file with both attribute suffixes changed together, and two read locations that select one class or the other. Both classes appear before the query. Verify in CPython that the correct completion reads the intended value and the other completion raises AttributeError. Use the two letters as the candidate list. Both source sites must align across the paired prompts.

Compare the four native predictions in each group with three interventions. Project and exchange the source activation difference at the selected definition, apply that identical edit when the other class is selected, and exchange the full activation at the selected definition as a positive control. Each physical definition serves both roles. Fit no weights on these examples. Publish margins and the source-dose equality check. Report switches separately for both selected classes, including when the queried definition is farther away.

Use groups where all four native margins are strictly positive, and require at least 100 such groups. Support for binding-sensitive use requires that whole-site exchanges and selected projected edits each cause at least 50% paired reversals, that projected edits on the unselected source reverse at most 10%, and that the lower 95% paired program-bootstrap bound on the selected-minus-unselected rate exceeds 25 percentage points. Report the rates and intervals even if the gate fails. This is conditional source selection in a controlled completion task.

Feng and Steinhardt previously used activation interventions to identify binding between entities and attributes in text. This test asks whether an already fitted letter edit respects the reader's choice of class in executable Python. It keeps the definition's edit identical while changing the query.
