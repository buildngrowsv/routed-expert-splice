# Can the 14B receiver learn to use the intact 7B coding expert?

For the first graft we fitted the interface to reconstruct the host's feed-forward output. Later, the native 7B expert's output moved the correct closing bracket by +2.111 log odds in its original network and by −0.009 after transplantation into the 14B receiver. Here we keep the expert in its original network and preserve the entire host. A small affine connection gets its training signal from the host's final repair loss. The question is whether the host can learn to use the donor's output through its existing block 28 and downstream computation. Model stitching and CALM establish precedent for training a bridge between independently trained, frozen models. Our test requires a stronger behavioral control on this specific synthetic skill. ## Comparison

Use the pinned Qwen2.5-Coder-7B and Qwen2.5-14B base checkpoints from the earlier studies. At the answer position, compress the frozen donor's final MLP output to 32 features. The projection retains the leading directions of within-triplet differences estimated on the training panel. Feature centering and scaling use training prompts only. After the 14B host completes block 27, add the output of a trainable affine map from the 32 features to the full residual width. The host's native computation through block 27 and all the subsequent weights are preserved. At inference the adapter uses a single prompt's feature vector.

Train three equal-size bridges on 64 new complete repair triplets (IDs 80000–80063), with four passes of four triplets per update, the same batch order, zero initialization, candidate cross-entropy and Adam at 0.002. Sources are the aligned donor features, the host's own block-27 MLP with an equivalently fitted 32-feature projection, and the donor features randomly permuted within the batch on every use. Save held-out logits for these three, the untouched host, the untouched expert and two donor interventions. With the aligned bridge frozen, set its input to its calibration mean, preserving the learned bias, or substitute the next triplet member's feature vector at each of the three positions. These interventions run on the same host prompts. The smoke uses separate run outputs and sets no scientific threshold.

Evaluate 256 new triplets (81000–81255), each with a uniquely executable one-character completion verified by the existing generator. A strict new solve must be correct on all three neighbors, fail on the untouched host, both matched bridges and mean-input ablation, and be solved by the intact donor. Count complete follows of the substituted donor as a separate attribution diagnostic. Require at least 25 intact-donor-only opportunities and at least ten strict new solves on those opportunities. Require the aligned donor to beat the host-feature bridge, shuffled bridge and mean-input ablation by at least five percentage points each, with each paired 95% triplet bootstrap interval above zero.

The score uses four candidate tokens on one family of synthetic Python repairs. A parser solves the task. The test measures use of the grafted signal in the host, with the cost of running a separate 7B prefix. A positive result would justify a follow-up that attempts to replace that prefix with a cheaper source and checks unfamiliar code.
