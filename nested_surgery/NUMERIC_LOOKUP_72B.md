# Can an imported number serve as an address?

The frozen 72B host completed all six responses in 26 of 64 threshold-routing groups. Among wrong responses in the two mirrored routing contexts, it chose the answer for the other selector in 40 of 42 cases. This follow-up gives the model an explicit dictionary lookup. The imported number is a **key**, which selects one of two recipient values. It never contains the expected answer.

```python
mode = 2
table = {2: 3, 6: 7}
return table[mode] + 1
```

In a paired program changing the key from 2 to 6 changes the answer from 4 to 8. Reversing the table's values in a separate prompt reverses the expected effect of the same edit. A third table assigns the same payload to both keys, so the same edit should preserve the answer. The generated answer digits do not occur as program numeric literals. This measures address use while removing threshold comparison from the task.

Keep the frozen Qwen2.5-Coder-7B donor, 72B recipient, fitted seven-dimensional interface, and cut after 17 host blocks. Score native, narrow donor, equal-norm orthogonal and whole-state edits at the key declaration. As in the threshold test, require 48 of 64 perfect native groups before running 256 separate test groups. Apply the same 80% switch, 95% preservation and 20-point paired advantage criteria.
