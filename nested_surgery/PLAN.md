# Does a block-27 graft transfer syntax repairs to new code forms after 16 examples?

The earlier delimiter experiment became perfect for every control when trained on examples from each evaluated form. Here all supervision comes from 16 existing, balanced, single-level repairs. Score a separate generator that nests complete arithmetic expressions inside a Python call, list, dictionary or conditional. Include a suffix beyond the gap and 12 executable test cases per question. The syntax parser is an exact inexpensive control. The research endpoint is whether transplanting a trained expert changes what the larger neural model can learn from little labeled data.

First compare the original Qwen2.5-Coder-0.5B donor and Qwen2.5-1.5B host on 256 fresh nested programs, balanced across punctuation. Proceed only if the smaller donor leads by at least five percentage points with a positive paired bootstrap lower bound. The selection panel uses depths 2–3. The primary panel uses 512 new programs with depths 4–6. Scores concern this generator and native fill-in-the-middle formatting.

For the qualified intervention, insert the donor's frozen final feed-forward module into one-based host block 27 with the previous training-only bridges. Train block 28 for eight Adam updates on the same 16 distinct single-level examples, batch 16, common order and rate 0.00002. Score all six previous controls, including native, zero, affine, shuffled, general donor and intact coding donor. Cache the full block-28 entrances, check cached logits against the end-to-end native model, and use identical final weights at donor-off and shuffled-at-inference evaluation. Report new solves relative to the untouched host, stricter new solves versus the equally adapted native host, losses/regressions and the exact IDs. Compare the on-minus-off advantage before and after fitting. Promote a fresh 16-example draw and independently generated panel only for a five-point intact advantage over both trained native and shuffled arms, a positive paired lower interval against each, and at least ten strict new solves that disappear when the donor is disabled. A second stage uses only the fixed new panel defined here. No tuning on it.

Prior work provides the interface and controls. [Original qualified benchmark](../task_transfer/README.md) · [Model stitching](https://arxiv.org/abs/2106.07682) · [Fill-in-the-middle training](https://arxiv.org/abs/2207.14255)

The first scheduled fit stopped before training when a cached four-candidate projection disagreed on a top choice with the full model. The corrected evaluator uses the original end-to-end, full-vocabulary scoring path for every reported prediction, before and after fitting. The cached path is used for training and checked for numeric agreement on eight prompts. The native baseline must exactly reproduce the original end-to-end logits. The task, budget, controls, seeds and decision thresholds are unchanged.
