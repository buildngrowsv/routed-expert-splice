# Does the final feed-forward module of the 7B donor carry the opening delimiter?

The intact 7B coder has a standalone repair advantage. The transplant selects its final feed-forward module. A separate question is whether that module's output supplies the opener-specific decision inside the functioning donor. We chose this test while the 14B splice was running, before inspecting its trained-coder or removal scores.

Use the same fresh 256 groups as the graft. At the final prediction token keep each prompt's own residual stream after attention, and change only the contribution from the last feed-forward module. Compare the native output, a zero output, and the output borrowed from the next opener within the same three-member group. The alternate group member differs by a single opening character. As a control for replacing an activation, also use one from a different prompt with the same opener and the nearest available token count. Match exactly whenever possible and report the number of exact matches. The reuse of the fresh graft panel makes this a mechanistic diagnostic on that panel.

First reproduce all 768 archived standalone donor choices. Report intact solves lost and newly rescued, paired whole-group differences, and how often originally correct answers switch to the substituted member's target. Require a net advantage of at least five percentage points for same-opener versus changed-opener substitutions on triplets, a positive lower paired 95% bound, and at least ten intact triplets preserved by the same-opener control and broken by changing the opener. Meeting this criterion would motivate testing whether the 14B-to-7B interface supplies the right signal to this module. A weak result makes a larger parameter sweep at the same site a low priority. The residual stream can already contain opener information, so an insensitive output intervention cannot rule out distributed coding.
