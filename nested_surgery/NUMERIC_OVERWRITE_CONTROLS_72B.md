# Does overwrite interference come from the donor edit or the host's use of the overwrite?

In the saved-value test, 14 answers changed to the edited overwrite plus the offset even though the program read the saved value. Every observed error under the irrelevant-site edit followed that pattern. The available whole-state control edited the relevant site, so it could not test whether the overwrite token is itself enough to create the effect. [Saved-value outcome and ranks](numeric_snapshot_72b_study/README.md)

Cross two values at the first assignment with two at the overwrite. For each fixed first value and read context, the paired prompts differ only at the later assignment. This makes the entire prefix through the previous token identical in a whole-state exchange. The full swapped state therefore comes from a run with the same saved value in its history. In the current-value read, that exchange should change the answer. In the saved-value read, it should preserve the answer. Compare the unchanged model, the earlier seven-coordinate donor edit, the same-site full-state exchange, and the equal-norm orthogonal edit. All edits occur at the overwrite token after block 17.

Use 64 independent eight-prompt screen groups and require full native accuracy on at least 40. The screen checks that the larger crossed design remains executable for the host. Use 256 disjoint test groups, requiring at least 100 fully native-correct groups and at least 80% switching by both active edits in all current-value prompts. Report exact answer preservation across all saved-value prompts and the fraction of groups with at least one exact overwrite-derived top answer where the native saved answer lost unique rank one.

For the overwrite-derived endpoint, resample complete groups with 5,000 draws. A difference of at least three points in either direction with a positive lower confidence bound supports a difference between edit types. If the entire donor–whole interval lies within ±3 points and each exceeds the orthogonal control with a positive lower bound, record shared interference. Otherwise the mechanism remains unresolved. This comparison uses frozen checkpoints and the same fitted mapping throughout.
