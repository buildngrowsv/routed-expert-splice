# Can the 7B donor supply a number the 14B host computes with?

The within-host integer edit reversed all 511 initially solved arithmetic pairs. Test whether an operand travels between the 7B coder and 14B host while the host still performs the computation. Fit seven directions in each model and a seven-by-seven ridge map on 512 paired programs that return their assigned value directly. The calibration does not use arithmetic.

Use 512 new pairs of host functions at indices 62000–62511. They add or subtract a nonzero integer. Both permitted answers differ from both possible operands. The donor sees independent functions with different identifier stems and surrounding code at indices 70000–70511. Those functions return the operand and do not contain the host's operator or output. Apply the translated difference at the known host assignment. Compare the untouched host, a same-norm random edit and a full host assignment-token swap.

Require at least 100 pairs with both native answers correct, and both the translated and full-token edit to reverse at least 80% of those pairs. The translated edit must beat the random control by at least 20 percentage points with a positive paired 95% lower bound. Report per-direction and operator breakdowns. This measures a counterfactual operand transfer in frozen models and a constrained output space.
