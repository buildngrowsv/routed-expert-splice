# Can a slice of a standard pretrained coder carry a whole identifier answer?

In a custom 285M byte model, a small linear readout decoded the declaration letter from either 192-value slice on every test pair. Neither slice alone reversed the model’s answer under an exchange. Swapping the full vector at the same byte reversed 458 of 461 eligible pairs. Repeat this distinction in two standard open checkpoints already cached on the Studio, Qwen2.5-Coder-7B and Qwen2.5-14B. Their residual streams have no designated fixed region. [Original experiment](https://github.com/buildngrowsv/fixed-reference-benchmark/tree/main/code_reference/origin_study) · [Activation patching methods](https://arxiv.org/abs/2309.16042) · [Causal abstraction](https://proceedings.neurips.cc/paper/2021/hash/4f5c422f4d49a5a807eda27434231040-Abstract.html)

Generate two executable functions that differ in their earlier declaration’s final letter. The query ends after the identical return prefix. An identifier ending in digits before the distinguishing letter makes it possible to change one source token and compare two single-token answers. Verify unchanged token alignment outside that one token, exactly one new token at the return under each completion, and exact decoding with both pinned tokenizers. Use 512 calibration groups and 512 separate evaluation pairs. To roughly match the original location at one fifth of model depth, read the outputs of blocks 6 and 10 respectively.

Fit a ridge classifier with one eighth of hidden coordinates from the declaration and 26 letter outputs. Repeat with the adjacent, disjoint one-eighth slice. The slices use fixed coordinate indices and do not select channels using the observed data. To test causal sufficiency, swap either slice or the full vector at the changed site and run the rest of the model. Copying the whole layer state between partners is the positive control. For each condition report two-candidate success and both-member reversals. A clean denominator of at least 100 pairs is required for interpretation. The original pattern counts as reproduced in a checkpoint if both probes solve at least 80% of all pairs, swapping the full site reverses at least 20% of eligible pairs and neither slice reverses 5% or more. The intervention samples one location and two coordinate slices. A full-site effect is the needed causal positive control in each model. A comparison across models with different tokenizers, sizes, training and architecture is descriptive. No model weights change. Based on the earlier frozen Qwen scoring, allow up to five minutes.
