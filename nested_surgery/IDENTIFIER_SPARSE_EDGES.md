# Can a time-matched set of eight direct edges carry the edit?

Block 20 had the largest hidden-state calibration signature. Opening that block alone reversed zero pairs. Closing it while leaving all the other edges open cost one reversal. Test whether the same calibration can select a small complementary set, and use a time-matched control to distinguish calibration strength from access at broadly similar depths.

Reuse the saved 31 block strengths from the earlier 64-group calibration. Split blocks 18–48 into four prespecified bins: 18–25, 26–33, 34–41 and 42–48. Within each bin, select the two strongest and two weakest remaining blocks, breaking ties by lower block number. This gives two disjoint eight-block sets with equal coverage of each depth bin. Lock both sets before evaluating 384 fresh groups at indices 116000–116383.

Apply the same rank-25 declaration edit and run five matched clean and edited schedules. Keep the final token's direct read of the source available throughout; close it entirely; open it only in the stronger set; open it only in the weaker set; or close it only in the stronger set. All other edges remain available. Examine the 384 matched-group outcomes for both queries. Require at least 100 clean groups across all five schedules, at least 60% unrestricted reversal on the edited class, and at most 15% on the other class and on the closed control. A sparse set is sufficient if it gives at least 70% reversal and its lower paired 95% bound relative to unrestricted is at least −15 points. Require at least a 20-point lower bound to conclude a stronger set beats the weaker set or that removing the stronger set reduces reversal materially. Report all comparisons and clean counts regardless of the decision. Estimated runtime nine minutes.
