The 7B coder supplied a target operand from one activation in the 14B recipient. Test the method in a larger frozen Qwen2.5 base recipient. Use the exact 7B donor and prior 14B affine map. Refit the same rank-seven interface for the 32B recipient using the original 512 direct-return calibration pairs. Intervene after block 13 of 64 in the 32B model, close to the fractional depth of block 10 of 48 in the 14B comparison. This changes the checkpoint and approximately matches relative depth.

Use both receivers on the same 512 new arithmetic pairs at indices 117000–117511, with separate donor functions at indices 118000–118511. Report unrestricted vocabulary results on each receiver and on their shared clean set. The existing 14B map remains frozen for its own arm. In the 32B recipient compare its fitted affine map, the paired-donor effect, equal-norm random directions, and a full host assignment exchange. Both receiver widths are 5,120. Also apply the old 14B basis and affine map to the 32B state without refitting, rescaling that perturbation to exactly the same norm as the fitted 32B edit. This separates useful cross-model coordinates from equal width.
