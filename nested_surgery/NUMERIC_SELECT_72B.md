# Does a transplanted operand matter only in the host context that reads it?

The unchanged 72B checkpoint solved 27 of 64 paired subtraction contexts, below their native gate. This new test uses the single-digit arithmetic form that the frozen model previously performed reliably. Give each reference two assigned variables with separate donor sources. In one context return the left variable plus a signed fixed offset. In its twin return the right variable plus that same offset. Pair two variants of the assignments and strip direct-copy shortcuts by keeping all computed answers distinct from the source digits. The expected selected answer changes across the pair. The recipient interface remains frozen and uses the existing 72B read and write matrices.

Qualify on 64 new groups and require complete native answers in both contexts for at least 48 groups. Evaluate 256 new groups with two contexts each. Compare the narrow edit at the read assignment, the same kind of edit at the unused assignment, a per-site equal-norm orthogonal edit at the read assignment, and full-state exchange only at the read assignment. Both prompts in both host contexts must switch under a selected edit. Both prompts in both contexts must retain their native answer under the unused edit. Require at least 100 native groups, at least 80% selected and full-state switches, at least 95% unused preservation, and a selected-minus-orthogonal lift of at least twenty points with positive lower paired bound. This tests selective operand use at a known site with both output paths matched, independent of the closed subtraction screen.
