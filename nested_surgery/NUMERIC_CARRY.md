# Can both donor edits change a complete number across the decimal boundary?

The two-operand experiment succeeded when the answer was one token. Keep the two single-digit operands and the exact saved map, and use sums whose four possible results cross ten. This tests whether the same independent edits affect an unrestricted multi-token prediction.

Use 128 fresh groups at indices 110000–110127 for the native screen. Each has two possible digits per operand, yielding four distinct sums, some one digit and some two. All four sums differ from the operands. CPython verifies each unique answer. Only proceed if at least 64 groups get all four complete numbers right without any intervention. Then test 512 independent groups at indices 111000–111511 and use separate donor functions at 112000–112511 and 113000–113511. Both donor programs return their own assigned digit directly. The pretrained models and saved map remain frozen.

Check the full vocabulary at every step of the intended output. Append the intended digits and score the exact prefix before each digit under the causal mask. A group counts only if every digit is the unique top token at its step and the following greedy token starts a newline or comment, or ends the sequence. Under these conditions greedy generation follows that exact number. Compare unmodified execution, both separately translated changes, both same-norm random changes, and both full host assignment states. Archive top token IDs, tie flags and terminator IDs. Require at least 100 initially correct groups and at least 80% success for both translated and full-state edits, a 20-point advantage over random, and a positive lower paired 95% interval. Report crossing-to-two-digit and crossing-to-one-digit results separately. Allow a few minutes if the screen passes.
