# Does the qualified route save synchronized inference time?

The fixed confidence route added 106 complete repairs on 2,304 new decoy groups with calls on 23.05% of prompts. The neutral control and the first eight batches' sparse execution audit passed. The reported 23.05% is a request fraction. Measuring actual synchronized time requires running the 14B model only on those selected inputs. Select from its scores before deciding whether to run the 14B, then pack only the selected rows for the 14B computation. Compare observed calls and full-panel complete-group choices with the archived exhaustive simulation. Measure three timed paths on 32 reference batches per layout, selected using a fixed seed: standalone 7B, both models with constant blending, and conditional blending. Use resident weights, preencoded prompts, per-batch warm-ups, three cyclically ordered synchronized repetitions and materialized candidate scores. Include the routing, selected packing, host and blend operations. Exclude initial downloads, startup, prompt encoding and first warm-ups. The result measures this paired batch workload on the Studio.

Require at least 1.5× median paired latency improvement against always blending on decoys, positive interval above 1×, at least 99.5% complete-group choice parity with offline routing on both layouts, and the same three-point decoy lift, positive lower bound, two-point neutral tolerance and one-third call-budget ceiling.
