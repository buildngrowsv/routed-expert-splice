# Does a 7B coding donor have a repeatable skill a 14B host lacks?

The 0.5B coding donor repaired all three counterfactual programs in just 7 of 256 groups. The unadapted 1.5B general host solved zero complete groups, and the graft also solved zero. Reopen the frozen donor qualification at a larger pretrained model scale. Use the same 768 archived prompts, the same four candidate tokens, and the same strict whole-triplet metric. Each triplet changes one earlier opening bracket while the suffix stays identical. A candidate counts only if it produces the unique executable repair. [Earlier evidence](opener_study/README.md)

Compare Qwen2.5-Coder-7B against Qwen2.5-14B, both base models at the released precision. Load one model at a time; verify each model's own tokenizer reconstructs every candidate completion. Report donor-only and host-only triplet IDs and a 95% bootstrap interval paired by triplet. Require at least 25 donor-only triplets, a net donor advantage of ten percentage points, and a positive lower bound before spending compute on an adapter. Any subsequent transfer uses fresh groups for evaluation and includes a matched adapted host, shuffled donor and donor removal. This is a qualification panel already used in the earlier study. The comparison changes pretrained checkpoints as well as parameter count. [Coding donor](https://huggingface.co/Qwen/Qwen2.5-Coder-7B) · [General host](https://huggingface.co/Qwen/Qwen2.5-14B)
