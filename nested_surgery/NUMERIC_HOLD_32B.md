# Does carrying the transplanted operand coordinates forward help a frozen 32B model compose?

The 32B carry study recovered 358/512 groups with one splice and 454/512 with two full-state replacements. Test whether explicitly preserving the seven donor-edited coordinates at each declaration through the next seven blocks improves complete carry. Keep the same prompts, donor, gain, early splice, metric, BF16 checkpoints and held-out groups. Restore only the original post-splice projection at the two assignment positions. Ordinary attention and the other dimensions of those positions continue to run. The restore is evaluated in float32 and cast back to the model dtype.

Compare the preserved donor edit with the identical archived one-shot edit, a matched orthogonal edit held by the same policy, and a no-donor control preserving its native seven coordinates. Use the previous full-state intervention for context. Require at least 95% native group preservation with the freeze alone. On groups solved natively in both runs, a five-point advantage over the one-shot edit with a positive paired lower bound and a twenty-point advantage over the held orthogonal edit are required for a route improvement. Separately report meeting the original 80% full-group target. Preserve the denominator and report both digit-length directions. The experiment tests whether fixing an activation reference helps the transplant, given the specified subspace and known assignment positions.
