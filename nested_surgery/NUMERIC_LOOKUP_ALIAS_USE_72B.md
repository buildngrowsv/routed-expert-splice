# Does the copied key become steerable where the dictionary actually reads it?

At the midpoint of Qwen2.5-72B, swapping the RHS token of the earlier copy statement changed zero lookup groups, while swapping a relocated numeral in a matched layout changed 117 of 143. The copy may become behaviorally active when the dictionary reads it. This benchmark tests that later stage in the same prompts and frozen model.
