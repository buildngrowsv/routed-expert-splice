# Can one donor forward pass supply an operand?

The existing seven-coordinate interface subtracts two donor activation states. That removes context shared by the two source prompts. A donor used as a component should be able to supply a target value from one pass. Fit an affine map on absolute projected donor and host activation states using the same 512 direct-return calibration pairs. Use the same seven fitted directions and regularization as the paired method.

On 512 fresh host pairs at indices 114000–114511, use the corresponding target operand from a separate donor function at indices 115000–115511. The one-pass arm sees only that target donor activation. It predicts the target seven-coordinate host state and replaces the original host projection at the assignment. A paired donor arm still subtracts its two activations as the positive interface control. Match the one-pass edit's norm in an orthogonal random subspace, and include native and full host activation exchange. Score the entire output vocabulary and the two candidate digits on the same passes.

Require at least 100 pairs where both original answers are unique full-vocabulary maxima. Require the paired and full-state controls and the one-pass edit to reverse at least 80% of those pairs. Require an advantage of at least 20 points above its same-norm random control with a positive lower paired 95% bound. If the paired arm remains strong and the one-pass arm fails, the result localizes a limitation of the absolute-state interface. It does not establish that all single-pass methods fail. Allow about two minutes based on the previous cross-model diagnostic.
