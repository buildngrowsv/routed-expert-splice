# Does dictionary key placement matter in a second frozen host?

Use the 256 disjoint dictionary groups from the 72B replication. Re-encode the early and late programs for Qwen2.5-32B, then add a comment to the late form that restores the early token gap under that tokenizer. Program answers and the dictionary mapping stay fixed. Compare native inference with a full-state key swap after block 13 in each order. The 32B cut is the previously used numeric intervention site. This test uses a separate pretrained host and the same input distribution.

The primary criterion compares the early and late forms in groups correct under both native orders. Require at least 100 shared groups, 80% late mirrored switching, 95% late constant-table preservation, and a late-minus-early gain of at least 15 points with a positive paired lower bound. Separately report all three forms over their common native cohort, with effect intervals based on complete groups. The comment control measures a specific input perturbation. The experiment tests whether the full-state placement effect survives in a second host and includes no donor calibration.
