# Does the 14B host feed the 7B expert an opener-specific signal?

The last coding module affected 40 of 54 complete repairs in its native model, but all 36 wrong answers that followed the replacement target moved from a closing brace to a closing parenthesis. The same expert inside block 27 of the larger host achieved zero complete repairs after adaptation. Test a specific failure point on 256 fresh groups (indices 40000–40255), with **both directions of every opener pair**. Fit no weights. Use the archived 14B-to-7B input map from the original transplant. [Donor diagnostic](donor_location_study/README.md) · [Graft](large_graft_study/README.md)

Hold each destination prompt’s entire 7B residual after final attention and its 7B vocabulary readout fixed. Supply the final expert either with its native input or with the 14B host’s block-27 input translated by the frozen map. Within each group apply the expert output from each of its three source prompts to each of the three destinations. These nine combinations are a complete within-group control for the native versus mapped input, including both original and changed openers. Score all four candidate logits, a zero contribution, and whole-group success using the correctly paired source. Verify that the native diagonal reproduces the standard full forward on a preflight batch. Record IDs, exact checkpoint revisions, and the input map’s file digest.

For each pair of opener types A and B, keep the destination fixed. Compute the change in log odds of A versus B when the module receives source A versus source B. Average over the three destinations and three unordered pairs with equal weight. A source-independent shift toward one punctuation mark cancels in this contrast. Room for the input map to preserve this signal requires a positive lower paired 95% bound for the native mean. Compare mapped signal to half the native signal with a group-paired interval. A positive lower bound qualifies retention of at least half. A negative upper bound points to attenuation on the input side. A crossing interval leaves this comparison unresolved. Report each opener pair, both same-source complete-group counts, and the zero-output control. The half-signal margin is an interpretation threshold chosen after the first diagnostic. The comparison holds the original donor residual and decoder fixed; it measures the **input side** and cannot certify successful transfer into the 14B model. Expected duration is under a minute based on the earlier standalone evaluation.
