# Swapping a late alias changed zero complete dictionary lookups in a 72B model

Moving a dictionary key declaration later previously made that site easier to steer. Writing a separate late copy of the original key did not reproduce that effect. At the late alias read, replacing the entire token activation with its counterpart changed **0 of 183** originally correct groups. Replacing it at the earlier source numeral under the same alias syntax changed **111 of 183**. The paired difference was −60.66 percentage points (95% interval −67.76 to −53.55). The late swap preserved the constant-output control in all 183 groups, with 181 preserved in the early swap.

The intervention uses the same 256 matched dictionary groups as the fresh lookup-transfer panel. Each group comprises the direct lookup, reversed dictionary values and a constant-output case, with two otherwise identical input prompts per case. It inserts `selected = mode` after the table and uses `table[selected]` in the return. The two prompts in each pair still differ in only the original key numeral. We swap the full residual activation between paired prompts after the same 17 of 80 layers in Qwen2.5-72B and score the exact next token across the full vocabulary. A switch requires both directions on the direct and reversed cases. The untouched model was correct on all six prompts in 183 groups. At this cut, supplying a counterpart's full state at the alias was insufficient to steer the answer. This test fixes the cut, alias token and surface form. It leaves other readouts, stages and alias syntax open. It shows that the earlier effect from relocating the declaration cannot be reproduced by simple placement of a late read in this setting.
