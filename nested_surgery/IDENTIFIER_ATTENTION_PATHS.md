# Does the edited declaration reach the final prediction directly or through other tokens?

The earlier wall left only one relay token at block 17 and preserved zero reversals at three tested token positions. This comparison leaves every possible relay available across all remaining layers, while separating communication through relays from direct reads of the edited declaration.

Use 512 fresh two-class Python groups at indices 90000–90511 in the frozen Qwen2.5-14B host. Each group has two declaration spellings and a query to either class. Both declarations have the same attribute suffix within a version. The edited source is always the earlier declaration. Use the original seven-block studies' 25-direction fit on 512 single-declaration calibration pairs. Apply that projected partner edit just after block 10. Each query receives exactly the same source edit for a given spelling.

Cross source state (original or edited) with three attention masks for blocks 11–48. The unrestricted mask is ordinary causal attention. The direct-only mask lets the source attend to itself and lets the final prediction token read it. Every other token is blocked from reading the source, so the edit cannot first travel through one of them. The relay-only mask blocks the final prediction token from reading that source directly. Other tokens can read the source and transmit the change. All three conditions use explicit Boolean causal masks and leave every other attention edge intact. The fit and first ten blocks run unchanged.

Use the intersection of groups where all four original outcomes remain correct under all three masks. Require at least 100 such groups, unrestricted reversals of at least 60% for the edited class and at most 15% for the other class before interpreting path differences. A path meets the sufficiency criterion if it reverses at least 70% of edited-class pairs and the lower paired 95% bound for its difference from unrestricted is at least minus 15 percentage points. Also report the paired direct-minus-relay effect, and call either more effective if the interval lies entirely beyond 20 points in its favor.
