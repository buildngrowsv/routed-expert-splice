# Qualify a trained feed-forward donor before transplantation

Train the final feed-forward subnetwork of Qwen2.5-Coder-0.5B on executable indentation quartets. Prediction: it will improve on the original coding model when its weights alone change. A larger host may learn the task equally well from the same examples. That would close the graft even if the donor clearly uses the new weights. The cheap non-neural control executes all four legal programs on the visible assertions.

Generate new draws using the prior indentation generator, namespace specialist-v1. Exclude all eight previously scored discovery families. Use the previous unscored allocation of 32 training families (1,536 prompts), the first four validation families for checkpoint selection (128), the remaining eight for qualification (256), and twelve different families for final evaluation (384). Keep all four same-program counterfactuals together. Each correct repair must pass all visible and hidden examples. Freeze this protocol before model scoring.

Train only donor block 24's feed-forward weights. Compare with the stronger native control that updates the whole of block 28 in Qwen2.5-1.5B. For each, use 96 Adam steps at 0.00002, batch 16, identical labeled data and matched orders 101, 211 and 307. Compare checkpoints at 0, 8, 32 and 96 by four-choice loss on the selection families alone. Record parameter counts, timing, peak memory, original baselines and weights/checksums. The adaptation budgets match data, order, rate and updates; the models' parameter counts and FLOPs differ.

Restore only the original donor feed-forward weights inside the adapted donor and rescore the same prompts. Report previously missed repairs that become correct and disappear on reversion, and previously correct repairs lost through specialization. Since it is the only trained component, reversion should reproduce the entire baseline. For a more specific input-dependence test, swap only the learned change in the feed-forward output at the scored position among the four versions of the same program. Keep the recipient's original branch and attention residual. Use all three cyclic nonidentity shifts with equal weight. Include the identity shift as a numerical check. A shared answer preference would survive this exchange.

Qualify a graft only when every training order shows (1) a donor lead of at least five percentage points over the adapted host on qualification, with a positive lower 95% paired family-bootstrap bound, (2) a donor gain over the original coding model of at least five points with new solves verified by exact reversion, and (3) the adapted host below 90% correct. Use 5,000 draws preserving families and quartets. Score independent final families after locking the decision, even for a failed gate, to characterize generalization and the exchange. If qualified, use the previously established block-27 interface, matched host-block-28 controls, and checkpoint-matched donor-off analysis on those final families. Otherwise stop before host transplantation. If endpoint competence is clear but no relative advantage appears, prioritize a held-out regime where a transferred expert might reduce the number of training examples needed rather than another architecture sweep.
